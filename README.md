# JasoWatch

JasoWatch는 **Mac에서 만들어진 분해형 파일명이 Windows에 들어왔을 때** 이를 자연스러운 한글 파일명으로 되돌리는 가벼운 트레이 유틸리티입니다. 실행해 두면 시스템 트레이에 상주하며 감시 폴더에 새로 들어오는 파일을 자동으로 확인합니다. 예를 들어 `한글 문서.pdf`를 `한글 문서.pdf`로 정리합니다.

파일의 내용은 건드리지 않고 이름만 바꿉니다. 설치 과정 없이 EXE 하나로 실행됩니다.

## 다운로드와 실행

1. [Releases](../../releases)에서 최신 `JasoWatch-win-x64.zip`을 받습니다.
2. 압축을 푼 뒤 `JasoWatch.exe`를 **다운로드 폴더에 그대로 두지 말고**, `문서\JasoWatch`처럼 장기 보관할 폴더로 옮깁니다. 포터블 앱이므로 그 위치에서 계속 실행합니다.
3. 작업 표시줄 오른쪽의 숨겨진 아이콘 영역에서 JasoWatch 아이콘을 찾습니다.

Windows SmartScreen 경고가 표시될 수 있습니다. 코드 서명에는 비용이 들어 현재는 서명된 실행 파일을 제공하지 못하고 있습니다. 불편을 드려 죄송하며, 신뢰할 수 있는 이 저장소에서 직접 받은 파일인지 확인한 뒤 **추가 정보 → 실행**을 선택해 주세요.

자동 시작을 사용할 예정이라면 특히 실행 파일을 옮긴 뒤 설정에서 자동 시작을 켜세요. JasoWatch는 현재 EXE 위치를 기억해 다음 로그인 때 그 위치에서 실행합니다.

## 사용 방법

기본 감시 폴더는 Windows의 다운로드 폴더입니다. JasoWatch는 실행 중 계속 상주하며, Mac에서 복사·압축 해제·다운로드한 파일처럼 분해된 Unicode 이름이 새로 들어오면 파일이 완전히 내려받아지고 잠금이 풀린 뒤 자동으로 정리합니다.

트레이 아이콘을 오른쪽 클릭하면 다음 작업을 할 수 있습니다.

- **감시 일시 중지 / 재개**: 자동 정리를 잠시 멈춥니다.
- **다운로드 폴더 열기**: 현재 감시 폴더를 엽니다. 아이콘을 두 번 클릭해도 됩니다.
- **기존 파일명 정리**: 이미 폴더에 있던 파일과 폴더를 한 번 검사합니다.
- **설정**: 감시 폴더, 하위 폴더 포함 여부, 제외 규칙, Windows 시작 시 자동 실행을 바꿉니다.

이미 다운로드되어 있던 파일을 정리하려면 작업 표시줄 오른쪽의 **JasoWatch 트레이 아이콘을 마우스 오른쪽 버튼으로 클릭**한 뒤 **기존 파일명 정리**를 선택하세요.

완료 알림의 큰 숫자는 실제로 이름이 바뀐 파일·폴더 수입니다. 검사한 전체 항목 수는 괄호 안의 참고 정보로만 표시됩니다.

`.crdownload`, `.part`, `.tmp` 파일과 `~$`로 시작하는 파일은 기본적으로 건너뜁니다. 설정에서 이 규칙을 바꾸거나 기본값으로 되돌릴 수 있습니다.

## 알아둘 점

- Windows 10/11 64비트용입니다.
- 네트워크 공유 폴더와 ARM64/32비트 Windows는 지원하지 않습니다.
- 같은 이름이 이미 있으면 기존 항목을 덮어쓰지 않고 `이름 1.ext`처럼 번호를 붙입니다.
- 호환 자모(`ㅎㅏㄴㄱㅡㄹ`)를 한글로 조합하지는 않습니다. Unicode 표준 NFC 정규화만 적용합니다.

## 개발과 검증

.NET 10 SDK에서 다음을 실행합니다.

```powershell
dotnet test .\JasoWatch.Tests\JasoWatch.Tests.csproj -c Release
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```
