MYTORY JASO WATCH

Mac에서 온 파일명,
Windows에서 자연스럽게.

Mac에서 만들어진 분해형 한글 파일명이 Windows에 들어오면, Mytory Jaso Watch가 트레이에 상주하며 새 파일을 자동으로 감지해 읽기 편한 이름으로 결합합니다.

한 번 실행하면, 계속 자동으로

Mac → Windows 파일명 결합
Mac에서 온 분해형 Unicode 이름을 Windows에서 자연스럽게 읽히도록 NFC로 바꿉니다.
트레이에 상주
창을 띄우지 않고 조용히 감시하다 새 파일을 자동으로 정리합니다.
안전하게 처리
내용은 건드리지 않고, 다운로드가 끝나고 잠금이 풀린 뒤 이름만 바꿉니다.

사용 방법

  1. 최신 릴리즈 ZIP을 내려받아 압축을 풉니다.
  2. Mytory Jaso Watch.exe를 다운로드 폴더에 그대로 두지 말고 문서\Mytory Jaso Watch처럼 장기 보관할 폴더로 옮깁니다.
  3. 그 위치에서 실행한 뒤 트레이 아이콘으로 감시 상태와 설정을 관리합니다.

Mytory Jaso Watch는 설치하지 않는 포터블 프로그램입니다. Windows 시작 시 자동 실행은 기본으로 켜져 있으므로, 실행 파일을 먼저 보관 위치로 옮겨 두세요. 원하지 않으면 트레이 아이콘의 설정에서 끌 수 있습니다.

기본 감시 위치는 다운로드 폴더입니다. 실행 뒤에는 트레이에 계속 상주하므로 Mac에서 받은 파일이 나중에 들어와도 자동으로 처리합니다.

이미 다운로드되어 있던 파일을 정리하려면 작업 표시줄 오른쪽의 Mytory Jaso Watch 트레이 아이콘을 마우스 오른쪽 버튼으로 클릭한 뒤 기존 파일명 정리를 선택하세요.

완료 알림에는 실제로 이름이 바뀐 항목 수를 먼저 보여 줍니다. 전체 검사 수는 괄호 안의 참고 정보입니다.

실행 시 경고창 처리 방법

첫 실행 때 Microsoft Defender SmartScreen의 Windows의 PC 보호 경고가 나타날 수 있습니다. 코드 서명에는 비용이 들어 현재는 서명된 실행 파일을 제공하지 못하고 있습니다. 불편을 드려 죄송합니다.

  1. 이 페이지 또는 공식 GitHub 릴리즈에서 직접 받은 ZIP인지 확인합니다.
  2. 경고창에서 추가 정보를 선택합니다.
  3. 앱 이름이 Mytory Jaso Watch.exe인지 확인한 뒤 실행을 선택합니다.

출처가 불분명한 파일에는 이 방법을 사용하지 마세요. 추후 코드 서명을 제공할 수 있게 되면 이 경고를 줄일 수 있도록 하겠습니다.

필요한 환경

Windows 10 또는 11, 64비트 환경에서 사용할 수 있습니다. 네트워크 공유 폴더는 지원하지 않습니다.
