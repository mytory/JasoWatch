JASOWATCH

Mac에서 온 파일명,
Windows에서 자연스럽게.

Mac에서 만들어진 분해형 한글 파일명이 Windows에 들어오면, JasoWatch가 트레이에 상주하며 새 파일을 자동으로 감지해 읽기 편한 이름으로 결합합니다.

무료로 다운로드
한글 문서.pdf  →  한글 문서.pdf

한 번 실행하면, 계속 자동으로

Mac → Windows 파일명 결합
Mac에서 온 분해형 Unicode 이름을 Windows에서 자연스럽게 읽히도록 NFC로 바꿉니다.
트레이에 상주
창을 띄우지 않고 조용히 감시하다 새 파일을 자동으로 정리합니다.
안전하게 처리
내용은 건드리지 않고, 다운로드가 끝나고 잠금이 풀린 뒤 이름만 바꿉니다.

사용 방법

  1. 최신 릴리즈 ZIP을 내려받아 압축을 풉니다.
  2. JasoWatch.exe를 실행합니다. 설치는 필요 없습니다.
  3. 트레이 아이콘에서 감시 상태와 설정을 관리합니다.

기본 감시 위치는 다운로드 폴더입니다. 실행 뒤에는 트레이에 계속 상주하므로 Mac에서 받은 파일이 나중에 들어와도 자동으로 처리합니다. 이미 있는 파일도 아이콘 메뉴의 기존 파일명 정리로 한 번에 검사할 수 있습니다.

필요한 환경

Windows 10 또는 11, 64비트 환경에서 사용할 수 있습니다. 네트워크 공유 폴더는 지원하지 않습니다.
