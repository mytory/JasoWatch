파일명, 자연스럽게 정리.

다운로드 폴더에 들어오는 분해된 Unicode 파일명을 감지해 Windows에서 자연스럽게 읽히는 NFC 이름으로 정리합니다.

다운로드를 기다림
파일 쓰기가 끝나고 잠금이 풀린 뒤 처리합니다.

사용 방법

  1. 최신 릴리즈 ZIP을 내려받아 압축을 풉니다.
  2. JasoWatch.exe를 실행합니다. 설치는 필요 없습니다.
  3. 트레이 아이콘에서 감시 상태와 설정을 관리합니다.

기본 감시 위치는 다운로드 폴더입니다. 이미 있는 파일도 아이콘 메뉴의 기존 파일명 정리로 한 번에 검사할 수 있습니다.

필요한 환경

Windows 10 또는 11, 64비트 환경에서 사용할 수 있습니다. 네트워크 공유 폴더는 지원하지 않습니다.
