개인정보 처리방침

시행일: 2026년 9월 22일

Mytory Jaso Watch(이하 “앱”)는 사용자가 선택한 Windows 폴더에서 분해된 Unicode 파일명을 NFC 형식으로 정리하는 로컬 트레이 유틸리티입니다. 앱은 개인정보와 파일 내용을 수집·전송하지 않습니다.

처리하는 정보

앱은 기능 제공을 위해 사용자가 설정한 감시 폴더 경로, 하위 폴더 감시 여부, 제외 규칙, Windows 자동 시작 설정, 최초 실행 안내 표시 여부를 PC의 %LOCALAPPDATA%\JasoWatch\settings.json에 저장합니다. 감시 중에는 파일명만 확인하며 파일 내용은 읽거나 수정하지 않습니다.

외부 전송 및 제3자 제공

앱에는 계정 기능, 광고, 분석 도구, 원격 서버 통신, 텔레메트리가 없습니다. 설정 정보와 파일명은 사용자의 PC 밖으로 전송되지 않으며 제3자에게 제공하지 않습니다.

보관 및 삭제

설정 정보는 사용자의 PC에만 보관됩니다. 앱을 종료하거나 제거해도 설정 파일은 자동으로 삭제되지 않을 수 있습니다. 원하면 %LOCALAPPDATA%\JasoWatch 폴더를 직접 삭제하여 설정을 지울 수 있습니다.
